title: 'Horixt'
description1: "For my final-year project, I chose to design and develop Horixt, a project management web application built for freelancers and organisations alike. Each user has their own personal workspace, while being able to join one or more organisations. The idea was to create a flexible, all-in-one tool that centralises task management, time tracking and collaboration in a modern, accessible environment."

description2: "Horixt includes several core features: a file manager with a lock/unlock system, a task manager (to-dos) with assignment, a note-taking module, and a time tracker linked directly to projects and tasks. For the design, I opted for a clean, professional interface based on neutral tones with touches of blue to improve readability and convey reliability. The whole application was built with Laravel and Livewire, which let me put my full-stack skills into practice while building a robust, scalable application."
