title: 'Tethr'
description1: "This project was built as part of my mobile application development course. The goal was to come up with an original idea, design it, and develop it entirely while learning Flutter and Dart. I chose to create Tethr, an app inspired by the Linktree concept: each user can create a profile, add various personal or professional links, and share a single centralised link. This project taught me a lot about the prototyping process, as well as about development and presenting the result to my teacher."

description2: "On the technical side, I used Firebase for data management and user authentication, and I integrated a deep-link system to generate custom QR codes for each profile. For the design, I favoured a modern, clean interface with a pastel colour palette, reinforced by minimalist icons to make navigation easier. User experience drove my choices, so that sharing links would feel smooth and intuitive. The result was very well received by my teacher, who praised both the technical quality and the clarity of the final result."
